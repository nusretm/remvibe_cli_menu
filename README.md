# RemVibe CLI Menu

Minimal, reusable **Dart CLI menu** package for RemVibe projects.

This repository will provide nested menus, dynamically computed items, optional status markers, explicit shortcuts, and asynchronous actions without coupling to Update Center or GitHub.

Development: CLI-1 initial implementation in a feature branch. Read `AGENTS.md`, `docs/WORKING_RULES.md`, and `docs/continuity/CURRENT_TARGET.md` on that branch before continuing. No implementation has been merged to `main` yet.
